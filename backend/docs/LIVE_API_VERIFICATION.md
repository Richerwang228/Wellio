## 联调发现并修复

- 原先默认高强度推理与 20 秒运行限制不适合实际请求。使用官方 OpenRouter provider，显式关闭推理，单次最多 4096 输出 tokens，Node 全轮 115 秒、FastAPI 租约 120 秒，并预留终结回执时间。
- 该模型在工具循环每一步同时施加 JSON response_format 时出现直接给出引言、承诺搜索、甚至声称修改而未调用工具的情况。工具循环改用原生 tool calling，最终 JSON 由 Zod 和 FastAPI 严格校验；模型自行选工具的菜单搜索实测通过。
- 可信用户意图及选中餐食目标传入模型上下文。明确且完整的修改、撤销、训练进度意图先要求实际工具调用；FastAPI 拒绝未尝试对应操作就直接完成，避免“已修改”而实际未保存。
- 聊天正文须独立完整，不把菜名价格等答案只放进 Today 摘要。仅省略号的占位回复不会被保存为完成。
- 即使上游忽略 abort，HTTP SSE 也按本地截止时间结束；迟到结果不能写入。新增离线回归覆盖不合作的上游、剩余租约与占位答案。

后端 pytest 248 项、Node 38 项通过；Node 构建及依赖审计通过。受控全链路覆盖会话隔离、重放、取消、写后重读、Undo、重启；真实调用只验证上表场景。
